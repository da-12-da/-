# 就这么定

当前部署请以 [GitHub-Pages部署.md](GitHub-Pages部署.md) 为准：前端通过 GitHub Actions 发布到 GitHub Pages，高德接口由现有 JZMD Cloudflare Worker 代理。公开 Worker 地址已配置在 deployment.json；高德 AK 只保存在 Worker Secret，真实接口可用性需单独联调。

移动端优先的单机聚餐决策 Web App。沿用提供的「参考图定制-轻甜紫.html」最终界面：亮紫立体按钮、粉彩转盘、深紫 GO、浅绿独立结果卡。正式界面没有原型总览、状态切换器、编辑器、头像、模拟状态栏或底部黑条。

## 启动

需要 Node.js 22.9 或更新版本。应用本身没有第三方运行依赖，不需要安装依赖或构建。

在此目录打开终端：

```powershell
npm start
```

也可以直接执行：

```powershell
node --env-file-if-exists=.env server.mjs
```

打开 http://127.0.0.1:5173 。停止服务按 Ctrl+C。Windows 可双击 `启动.cmd`，前提是 Node.js 已安装并加入 PATH。

手机真机访问需要通过 HTTPS 提供服务；浏览器定位在普通局域网 HTTP 地址下通常不可用。可设置 HOST=0.0.0.0 供局域网访问并手动选择区域；正式使用应由 HTTPS 反向代理转发到 Node 服务。不使用原型 HTML 的 file:// 打开方式运行正式应用。

## 已实现

- 五页流程：想法录入 → GO 转盘 → 独立结果 → 附近商家 → 目的地确认。
- 初始为空清单，无预设餐饮选项；用户自行添加，至少 2 项才能开始转盘，最多 8 项。支持删至空清单、12 字限制、空白与重复校验、增删改；新清单仅保存在当前浏览器，不再自动载入旧版默认清单，存储不可用时仍可使用。
- Web Crypto 拒绝采样保证等概率；按目标扇区中心计算最终旋转角，动画完成后跳页。动画中禁用 GO、返回和修改；支持减少动态效果设置。
- 每次抽出新结果时，播放粉彩彩带飘落动画和用户提供的「音效-双音轻扬.wav」。彩带不拦截点击，约 4 秒后清理；离开结果页或切到后台立即停止，返回旧结果不重复播放。开启减少动态效果时关闭彩带动画。
- 320px 手机、小屏横屏、桌面布局；转盘按可用宽高缩放，区域不产生滚动条。
- 当前位置与手动城市/区域输入；默认 3 公里，支持 5/10 公里；最多三家、实际数量、评分/评价数缺失时隐藏、来源和排序说明。
- 加载、定位拒绝、定位失败、未接入、空结果、接口失败、重新查询；中止旧请求并忽略过期响应。
- 修改选项、重新抽取、切换位置或范围后清除对应旧状态。
- 保留高德、百度 HTTPS 导航入口；高德商家返回 GCJ-02 坐标，两种地图均传递所选商家的正确坐标类型。

## 尚需外部配置

**真实商家推荐尚未接入。没有提供或使用接口凭证，也没有验证任何供应商账户的权限、配额或线上可用性。** 默认商家页显示「商家数据未接入」，不会回退到原型样例。

已完成独立的高德 JZMD Worker：坐标转换、区域解析、Place 检索、筛选和错误处理。前端通过 deployment.json 中的 workerBaseUrl 直接请求 Worker。完整配置及 Secret 操作见《高德地图接入部署.md》；旧 provider.mjs 为早期通用网关适配，当前高德部署不使用它。

地图跳转代码与链接参数已经测试；**尚未在实体手机安装的高德/百度客户端完成真实商家导航验收**。百度链接可尝试唤起客户端，高德使用其 Web 导航入口；是否唤起受平台、浏览器和地图安装情况影响。桌面地图可能需要自行填写起点。应用不绘制样例路线，不估算行车时间。

## 结果页彩带与音效

播放代码保存在 `public/app.js`；音频为用户提供的「音效-双音轻扬.wav」，原样复制为 `public/success.wav`，保留原始音色、音量与节奏，不再合成 C–E–G 音符。服务端通过 `/success.wav` 提供 `audio/wav` 文件。点击 GO 时启用 Web Audio 并预加载、解码音频，进入结果页后播放一次；迟到的加载响应不会在离页后播放。无需外部音频服务或额外依赖。浏览器限制播放、设备静音或文件加载失败时，结果和后续操作仍正常。部署时须包含 `public/success.wav`，服务端改动后需要重启。

新增专用验收命令（浏览器环境安装方式见下文）：

```powershell
npm run test:celebration
```

覆盖彩带生成、WAV 解码及单次播放、按钮不被遮挡、离页停止、返回不重播、再次抽取、动画清理和减少动态效果。自动测试验证音频引擎与声源调度；实际听感和音量可在设备上试听。

## 演示与测试数据

正式应用没有启用演示模式。`tests/` 中的虚构商家仅用于自动化测试，并标注「自动测试虚构数据」。测试截图中成功推荐/确认页同样是测试数据，不能作为推荐使用。生产适配层拒绝带 `demo: true` 的商家，导航函数也会拒绝演示目的地。

## 验证

```powershell
npm test
```

10 项 Node 测试覆盖输入校验、2–8 扇区与指针的一致性、拒绝采样、地图坐标顺序、接口配置、半径筛选、去重排序、缺失字段、错误响应及静态文件白名单。

浏览器验收需要 Playwright 和 Chromium/Edge：

```powershell
npm install --no-save --package-lock=false playwright
npm run test:browser
```

Windows 默认使用已安装的 Microsoft Edge；非默认路径可通过 `BROWSER_PATH` 指定。测试也支持通过 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块绝对路径。其他平台可先执行 `npx playwright install chromium`。

`test-results/browser-results.json` 保存验收结果；PNG 截图覆盖录入、转盘、结果、无数据、测试推荐与测试确认页。浏览器测试不访问外部商家，不实际打开导航。已通过 320×568、390×844、667×375、844×390、1280×800 视口及 3 秒真实动画检查。

## 文件

- `public/`：正式页面、原型风格样式、前端状态与转盘/导航算法。
- `server.mjs`：静态文件服务和同源接口，仅公开白名单文件，不公开配置或源码目录。
- `provider.mjs`：服务端商家适配层、输入与返回校验、距离计算和排序。
- `.env.example`：无密钥配置模板；复制为 `.env` 并按实际环境填写。
- `tests/`：算法、适配层、HTTP 与浏览器验收。

当前实现不包含登录、多人同步、支付预订、景点住宿或原型编辑器，也未部署到线上。


## GitHub 仓库原始介绍

# -
和朋友一起旅游时，大家经常需要临时决定“吃什么、去哪儿吃”。每个人都有不同的想法，很难快速达成一致。 本产品聚焦旅行多人聚餐决策场景，通过“收集想法 → 转盘选择 → 附近商家推荐 → 目的导航”的完整流程，帮同行小伙伴快速结束选择纠结。不再反复拉扯、互相妥协，把选择难题变成一场轻松愉快的社交小游戏。
