

# 项目名称

> **就这么定**：一款旅行决策工具。当你和朋友在一起玩、不知道该听谁的、该去哪、或者无聊没想法的时候，把你们的想法告诉**它**，让**它**帮你决定。最重要的是，不只是做决策，还可以体验选择的乐趣。

---

## 一、项目背景与痛点

### 1.1 背景

和朋友一起旅游时，大家经常需要临时决定

“吃什么呢？”，“去哪儿吃呢？”，“接下来玩什么好呢？”，“太无聊了，不知道去哪里。”

每个人都有不同的想法，很难快速达成一致。

本产品聚焦**多人旅行决策场景**，通过"**收集想法 → 转盘选择 → 附近商家推荐 → 目的地导航**"的完整流程，帮同行小伙伴快速结束选择纠结。不再反复拉扯、互相妥协，把选择难题变成一场轻松愉快的社交小游戏。

### 1.2 痛点

- **意见难统一**：有人想吃火锅，有人想吃烧烤，有人觉得"我都行"。在大家难以抉择时，往往采用少数服从多数的方法，或者一直纠结其中难以选择，讨论很久也定不下来。
- **陌生地点不好选**：旅行途中不了解周边商家，需要反复搜索和比较。
- **选完品类还得选店**：决定吃火锅之后，仍然面临"去哪家"的第二轮纠结。
- **操作不够连贯**：讨论、随机选择、查店和导航分散在不同工具中。

---

## 二、需求详情

| 需求 | 详情 |
| :--- | :--- |
| **添加大家的想法** | 支持添加、编辑和删除选项，例如"火锅、烧烤、自助、小炒"。首期由一人在同一台手机上汇总大家的意见。 |
| **转盘随机选择** | 将选项展示为转盘，每个选项被选中的概率相同。点击后转动并突出显示结果，支持重新转动。 |
| **推荐附近同类商家** | 获得位置授权后，根据抽中的品类，默认搜索周边 3 公里内的商家，推荐口碑靠前的 3 家。<br>展示店名、距离、地址、评分，以及数据源实际提供的好评率和评价数量。标明推荐依据，不将评分换算为好评率；不足 3 家时展示实际数量，并支持扩大范围。 |
| **确定商家并出发** | 用户从推荐商家中选择一家，确认本次目的地，并打开地图导航。拒绝定位时，支持手动输入目的地或所在区域。 |

## 三、产品方案

### 3.1 MVP 版本规划

#### MVP 1.0

- **目标**：在同一台手机或车载端口上跑通"录入餐饮选项 → 转盘选品类 → 推荐附近 3 家店 → 选店导航"的完整流程。
- **包含功能**：
  - 餐饮选项的添加、编辑、删除功能
  - 概率转盘显示、运转及结果展示
- **暂不包含**：多人在线同步编辑、投票、账号体系、预订支付，以及景点、住宿等其他旅行决策。
- **上线前提**：没有真实数据时，不展示虚构推荐。
- **验证指标**：完成通路。

#### MVP 2.0

- **目标**：接入真实商家信息，接入地图。

#### MVP 3.0

- **目标**：车载功能同步上线，接入语音功能。
